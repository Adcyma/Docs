# Compliance Reports

import Image from '@theme/IdealImage';
import reportsImg from '@site/static/img/ComplianceReports.jpg';

The Compliance Reports page lets you generate audit-ready evidence reports for common security and compliance frameworks. Select a framework, set a date range, and Adcyma compiles the relevant evidence from your environment into a downloadable report.

:::info
Compliance Reports is currently a **beta** feature.
:::

<Image img={reportsImg} alt="Compliance Reports" className="doc-screenshot" />

## Supported Frameworks

**SOC 2**
Trust Services Criteria evidence: logical access, monitoring, change management, and user inventory.

**ISO 27001**
Information Security Management evidence: user access, logging, HR security, roles, and managed user data.

**NIS2**
Network and Information Security Directive evidence: access control, lifecycle management, monitoring, and configuration data.

## Generating a Report

1. Click the framework card you want to generate a report for
2. Set the **From** and **To** dates for the reporting period (defaults to the last 30 days)
3. Click **Generate Report**

Report generation runs in the background. The page shows the report's status while it processes. When it's ready, a **Download Report** button appears.

## Report History

The history table shows all previously generated reports with:

| Column | Description |
|---|---|
| Framework | Which standard the report covers |
| Period | The start and end date of the reporting period |
| Generated | When the report was created |
| Generated by | Who requested the report (or System for scheduled reports) |
| Status | Completed, Pending, or Failed |

Click **Download** on any completed report in history to retrieve it again, even long after it was generated. Failed reports show the error instead of a download link.

## Best Practices

- Generate reports regularly as part of your compliance calendar, not just before audits.
- Keep downloaded reports in your compliance documentation system alongside other evidence.
- Use consistent date ranges (e.g., always generate monthly or quarterly) to make it easy to compare reports over time.
- If a report fails, check that your directory connection is active and try again.
